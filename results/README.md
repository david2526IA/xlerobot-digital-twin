# Results

Long PPO experiments are intentionally deferred to a more capable computer.
There are no full baseline or sim-to-real results in this repository yet.

When remote training is complete, add a small Markdown or CSV summary here with
the commit SHA, configuration, device, seeds, held-out episode count, metrics
and the label **simulation only**. Keep checkpoints and large rollouts outside
Git or publish them as versioned release artifacts.

See [remote training instructions](../docs/REMOTE_TRAINING.md).
